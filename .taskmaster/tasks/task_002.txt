# Task ID: 2
# Title: Database Schema Design
# Status: pending
# Dependencies: 1
# Priority: high
# Description: Design and implement the database schema for users, events, invitations, verification status, and reputation system.
# Details:
1. Create PostgreSQL database schema with the following tables:
   - Users (id, email, name, verification_status, consent_preferences, reputation_score)
   - Events (id, host_id, title, description, location, date_time, capacity, status)
   - Invitations (id, event_id, user_id, status, invite_code)
   - Attendance (id, event_id, user_id, check_in_time)
   - Feedback (id, event_id, user_id, vibe_score, comments)
   - Reports (id, event_id, reporter_id, reported_id, description, status)
2. Implement database migrations using Alembic
3. Set up Redis for caching and session management
4. Create database access layer with SQLAlchemy ORM

# Test Strategy:
Write unit tests for database models and migrations. Verify that all relationships between tables work correctly. Test database performance with sample data sets.
